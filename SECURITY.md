# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |
| Earlier versions | No |

## Report a vulnerability privately

Use [GitHub private vulnerability reporting](https://github.com/grgy078033/tugboat/security/advisories/new). Do not open a public issue for a suspected vulnerability.

Please include:

- the affected version or commit;
- the security impact;
- minimal reproduction steps;
- any known mitigation.

Remove secrets, personal data, private conversations, and identifying health or project information before submitting. The maintainer will review the report and coordinate disclosure when appropriate.

## What belongs here

Security reports may cover instructions or repository changes that could cause unintended data disclosure, unsafe tool use, permission bypass, or another concrete security impact. Unexpected skill behavior without a security impact belongs in a [skill behavior report](https://github.com/grgy078033/tugboat/issues/new?template=02-behavior-report.yml).
